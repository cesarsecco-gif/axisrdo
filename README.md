# AXIS RDO
> **Plataforma de Gestão de Diários de Obra e Relatórios Fotográficos de Engenharia**  
> Desenvolvido por **Axis Consultoria e Planejamento**

---

## 🏗️ Visão Geral
O **AXIS RDO** é uma solução para gestão de obras, rodovias e projetos de infraestrutura, permitindo:
- Gestão centralizada de obras, contratos e frentes de trabalho;
- Emissão de **Diários de Obras (RDO)** técnicos com suporte a lotes e conferência de serviços;
- Organização inteligente de fotos por data, estaca, coordenadas GPS e leitura automática de carimbos OCR;
- Acompanhamento de efetivo da equipe, controle de equipamentos, pluviometria e ações corretivas;
- Exportação em PDF executivo de alta fidelidade e planilhas analíticas consolidadas (XLSX);
- Identidade visual e cabeçalhos 100% personalizáveis por obra/cliente (White-Label).

---

## 🚀 Stack Tecnológica
- **Frontend:** React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons
- **Backend:** Node.js, Express, jsPDF, fflate
- **Processamento:** Tesseract.js (OCR), @napi-rs/canvas
- **Ambiente de Produção:** Docker / Node.js 20+ em Linux VPS (Hostinger)

## 💻 Desenvolvimento
```bash
# Entrar no diretório do código
```
